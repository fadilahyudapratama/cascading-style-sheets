Inserting CSS

CSS sendiri memiliki 3 cara dalam penggunaanya terhadap HTML yaitu: inline, internal dan eksternal. pada penggunaan inline berarti css yang di masukan langsung kedalam element HTML, sedangkan internal berarti css yang di masukan di letakan pada element head, dan yang terakhir eksternal berarti css yang dimasukan berdasarkan sebuah link eksternal css.
