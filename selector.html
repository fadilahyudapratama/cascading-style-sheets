Selectors

CSS selectors adalah cara untuk memilih elemen HTML yang akan diberi style atau tampilan pada halaman web. Dalam CSS, ada beberapa jenis selectors yang dapat digunakan untuk memilih element HTML, yaitu:

1 - Selector element

Selector Element di gunakan untuk memilih HTML berdasarkan nama element contoh pada Judul di atas yg di berikan color: blue

2 - Selector ID

Selector ID digunakan untuk memilih elemen HTML dengan atribut id, Setiap atribut id harus unik pada halaman web. contoh pada point 2 judul selector Id yg diberikan background-color: gray

3 - Selector Class

Selector class digunakan untuk elemen HTML dengan attribut class. setiap atribut class dapat digunakan pada beberapa elemen HTML. contoh: pada judul point 3 selector class yang di berikan font-size: 16px

4 - Selector Universal

Selector Universal digunakan untuk memilih semua elemen HTML pada halaman web. COntoh pada bagian margin dan padding pada semua elemen HTML

5 - Selector Group

Selector Group digunakan untuk memilih beberapa elemen HTML dengan properti yang sama. contoh pada judul point 5 yang di berikan coor: red
